# AEGIS Community Code of Conduct

AEGIS welcomes contributors regardless of experience, background, identity, or whether their work is written manually or with AI assistance.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique code and evidence, not people.
- Disclose uncertainty and correct mistakes openly.
- Respect privacy, licenses, security boundaries, and maintainer decisions.
- Keep discussions relevant to improving AEGIS.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information, secrets, precise personal location history, or vulnerability details.
- Spam, deceptive promotion, fabricated telemetry, or intentionally misleading claims.
- Using AEGIS or its community to facilitate unauthorized surveillance, intrusion, or harm.
- Flooding the repository with duplicated, untested, or automatically generated issues and PRs.

## Enforcement

Maintainers may edit, hide, close, lock, or remove contributions and restrict participation when necessary to protect the project and community. Serious security or safety concerns may be escalated to GitHub or the appropriate authorities.

Report conduct concerns privately to the maintainers through the repository owner’s GitHub profile. Do not include sensitive evidence in a public issue.
