# Demo — Recientes

1. Open mobile `¿A dónde vas?` sheet (`SearchBar` `variant="mobile-nav"`).
2. Search an OSM place (existing geocode), tap **Abrir ruta** or locate.
3. Re-open with empty query: **Recientes** appears under Casa / Trabajo.
4. Tap a recent row → routes/selects; long-press → removes one; **Limpiar** → clears all.
5. No Google Maps Platform keys; storage `aegis.recent-destinations.v1` only.
